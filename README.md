# SolidWave Tracker on phones

The phone and web version of SolidWave Tracker, served by GitHub Pages. On a phone, open the link and add it to the
home screen (iPhone: Share › Add to Home Screen; Android: the browser's menu › Add to Home screen or Install app). It
opens like an app, with its own icon.

These files are made by `web.js` in the desktop app's folder (ProjectTrackerDesktop). Don't change them by hand: the
next build writes over them.

- `preview/`: a test copy with pretend sign-in and made-up data, to try changes on a phone before they're released.
- The real app sits at the top once it's released.

No one's data is here. It stays in the owner's account online, behind sign-in.
